A single-joke entry for One Line, One Laugh by zxpast (handle swift-pika-45).

`main.ts` runs on Node 22 using only the standard library and emits just
one joke line into `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when that variable is not set). The output is fixed every time: one hard-coded
string, with no clock, no randomness, no network and no files read.

The entry (135 characters):

> I hid my chocolate in the detergent box; my kids found it, do the laundry now, and ask, 'Mom, why does the chocolate taste like clean?'

To run it: `node main.ts` — run it twice; both runs must come out byte-identical.
